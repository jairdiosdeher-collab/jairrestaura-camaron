# JAIRRESTAURA CAMARÓN

Escuela digital gratuita de camaronicultura de agua dulce, enfocada en *Macrobrachium rosenbergii* y en el aprendizaje responsable para Colombia y Latinoamérica.

## Objetivo

Ofrecer formación progresiva, herramientas de registro y apoyo para planificar sistemas de cultivo a pequeña escala. La aplicación es educativa: no sustituye asesoría técnica, permisos, análisis de agua ni validación local.

## Desarrollo

Aplicación web adaptable a móviles construida con React y Vite. No requiere cuenta ni servicios pagos para ejecutar la versión inicial.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Estado
